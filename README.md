# CrewSignal

A calm, offline-first daily health companion for a Mars transit crew.

CrewSignal is a frontend prototype: each crew member has a personal dashboard
with simulated live vitals, a daily check-in, a wellbeing history, a report
view for sending summaries to Earth, and a stepped emergency / private-support
flow. Everything is stored on the device, so the app keeps working when the
link home does not.

## Repository layout

```
backend/    placeholder server for now (server.js is a stub)
frontend/   Next.js app — all of the current functionality
```

## Running it

The frontend is the only part with real code at the moment. It uses pnpm.

```bash
cd frontend
pnpm install
pnpm dev
```

Then open http://localhost:3000.

Other scripts:

```bash
pnpm build   # production build
pnpm start   # serve the production build
```

## What the app does

- **Home** — pick a crew member, check the mission clock, toggle theme.
- **Daily** — dashboard per astronaut: live simulated vitals (heart rate,
  skin temperature, blood pressure, motion), a body map, reading details,
  sensor-contact quality (usable / poor contact / disconnected, with an auto
  override), sleep and mood history, and a wellbeing score.
- **Check-in** — daily form for sleep, blood sugar, mood, stress, and
  symptoms; saved to `localStorage` per crew member and per day.
- **Reports** — assembled summary of check-in and vitals with an offline
  toggle and a private-data toggle; "queued for Earth" confirms locally only.
- **Emergency** — guided flow for an emergency situation report, plus a
  private support request that is kept in a local outbox.
- **Theme** — light / dark, persisted per device.

## Status and limitations

- The backend is a stub, so nothing actually leaves the device: reports and
  support requests are simulated end to end.
- Vitals are generated by a simulation hook (`use-health-simulation.ts`), not
  read from real sensors.
- Data lives in `localStorage`, so it is per browser and per day.
- No authentication, no server persistence, no tests yet.
